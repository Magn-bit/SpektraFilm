# Windows 0.8.2 验证范围

本版包含风格预设、导入调度与文件选择位置记忆的更新；沿用暖白灰绿界面和现有字体。Android 仍为 0.5.0/code23，开发源码的共用预设解析器已同步但未构建 APK。

## 本轮变化

- 风格入口显示当前名称，去掉“浏览精选”。首项为“无预设”，之后依次为8款人像、10款风光；分类过滤仍保留首项。选择“无预设”恢复风格字段（含通道混合器），保留曝光、白平衡、胶片、构图与蒙版。
- 导入入口只做词法路径规范化和去重；文件存在检查、路径解析和元数据读取交给后台。拖放/粘贴的 MIME 检查不再逐张访问磁盘。第一张独立登记并优先预览，其他照片继续分批读取；缩略图按需加载，源尺寸及最终输出策略不变。
- 照片导入选择器共用确认过的来源目录；照片导出使用独立目录记录。重开选择器及重启应用后恢复，取消不覆盖记录，目录已删除时回退到存在的父目录。自定义文件夹图标查询关闭，避免额外调用磁盘或外壳扩展。

## 关键节点

- `tests.test_import_responsiveness`：后台故意阻塞后续文件时首张先显示，GUI计时器继续运行；入队期间禁止调用 `Path.resolve/is_file`；真实文件/目录对话框确认、取消、共同来源目录、独立导出目录和缺失目录回退。
- `tests.test_style_presets` 5项与导入入口4项回归通过；不是全套历史回归或全机型RAW测速。
- 风格目录两张预览尺寸样片生成对照图；真实源QML界面1366×768/1440×900名称与“无预设”范围验证通过，无QML警告。
- 确切Windows候选运行检查通过：GUI/CLI、导入首图、图库、编码打样、原尺寸TIFF/ICC、同GUI自动化及14项编辑精修。新增预设节点使用实际列表和按钮点击，检查当前名称与“无预设”范围；QML无警告。成品记录见 `release/Evidence/Windows-0.8.2/review.json`，相关截图见其 `workspace/refinements/`。
- 目录记忆另由独立进程读取落盘的QSettings记录确认；这不是运行全套RAW吞吐测试。前两次验收因测试替身、不可见控件和复用临时图库失败，最终使用修正后的脚本和新的验收目录通过，未把失败结果冒充成功。

导入入队计时只表示路径登记和调度开销，不能代表RAW首帧、解码或完整导出耗时；故意阻塞IO用于确认响应性，不代表外置磁盘吞吐。原光谱/编码专项复用既有证据，不重复大RAW基准或哈希测试。
