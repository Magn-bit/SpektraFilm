# 图库筛选与导出结果 · 2026-11-09

本轮继续既有 PySide6 / Qt Quick 和原生图库 SDK，不改快速会话，也不增加评级。

## 图库

`LibraryWorkspace.qml` 的筛选入口切换左侧分面。日期按年/月，机身、镜头、类型和关键词支持多选，同维度 OR、跨维度 AND。`images.facets` 在全库当前集合上统计，每个分面排除自身选择、保留其他条件，因此数字不受当前64张分页限制。已选但数量为0的条目保留，可直接取消。

`已有显影调整` / `尚无显影调整` 使用 SDK `has_edit`，表示是否保存过调整，不代表已导出，也不冒充参考软件的渲染缓存索引。关键词来自库内真实元数据（包括导入的 C1 只读元数据），当前未增加本地关键词编辑。

按库保存搜索、分面、排序方向、展开状态。查询与回包按 epoch/序列隔离；切库不会采纳旧库回包。筛选树使用独立通知，不因每个 helper 忙状态重建。保存参数后合并刷新显影状态，保持原来的保存冲突及关闭屏障。

`library_metadata.py` 使用单工作线程、每批最多64文件，通过批量 ExifTool 或 PIL 文件头读取补齐尺寸、日期、相机/镜头与曝光信息。无 RAW 解码、无整图像素驻留；未知信息保持未知。元数据刷新650ms合并，并在切库/关闭时隔离迟到结果。

关键验证：`scripts/verify_library_facets.py`，6张带真实EXIF的小JPEG，实际原生 helper。已验证组合计数、日期、编辑状态更新、关键词、清除、按库恢复、真实QML点击；QML消息0。

证据：`output/library-facets/verification.json`、`library-facets-1366x768.png`、`library-facets-cleared-1366x768.png`。截图为合成色块夹具，用来检查布局和真实EXIF行为，非照片效果示例。1366×768逻辑，系统150%DPI。已查看，未见重叠/底部遮挡。

## 导出

`ExportResults.qml` 在普通导出和输出配方页显示每张源文件的等待、处理中、完成、失败或取消。失败原因直接可读；结果区在滚动参数之外，主要导出操作仍可达。列表有界虚拟化，深色失败状态用单独表面/文字颜色。

`ctrl.retryFailedExports()` 由主控制器实现，仅重试失败源，沿用首次导出的不可变参数及配方快照。导出页开始任务后保持打开；导出结束重新请求打样，修复因释放 proof 导致最终页面大面积空白的问题。导出期间停止打样请求，避免争用。

关键验证：`scripts/verify_export_results_ui.py`。480×320真实照片：一次一成功一缺失源失败，修复失败源后点击真实重试按钮；验证只处理失败项、期间当前曝光改为+2也不改变快照、结果仍480×320。1366×768与1440×900截图实际查看。配方打样区798×678逻辑、右栏有界，结果不覆盖参数及导出按钮。无大RAW测速、无哈希。

证据：`output/export-results-ui/verification.json`、`recipe-failure-1366x768.png`、`export-completed-1366x768.png`、`export-completed-1440x900.png`。

剩余：最终候选EXE集成由发布节点验证；本节点不声称完整包/Android已验。当前配方页改动中的customNaming绑定日志已交主线程收尾。

## 来源管理与照片信息

`LibrarySources.qml` 使用真实 `folders.list`、`locations.list` 与当前C1来源信息，展示多个监视文件夹、在线状态、数量、上次刷新；添加、逐项/全部刷新、同步C1与重新定位均接原有SDK。刷新无新增时也更新状态与时间。来源名称优先显示文件夹名，路径省略但可悬停看全文；已被监视根覆盖的位置不会重复出现。

取消监视必须先显示统一风格的范围说明：只停止自动刷新，已导入照片、持久调整、磁盘原文件全部保留。实际 `folders.remove` 仅删监视关系，不删除图像。只读C1来源禁止本地监视变更。

`LibraryInfo.qml` 是图库内按需打开的独立滚动侧栏，保持照片网格可用。数据由当前选中项的真实header元数据给出，相机、镜头、拍摄时间、尺寸、格式、ISO、光圈、快门、焦距、曝光补偿及源路径；无数据为“—”，多选不同/部分缺失为“多种”，不会制造值。

新增关键节点 `scripts/verify_library_sources_info.py`，未重跑原facets整套：两个原生监视根，真实EXIF小JPEG，点击刷新和取消确认、持久调整读取、原片保留、不再导入已取消根的新文件、继续导入仍监视根、Info多选摘要。`output/library-sources-info/verification.json` passed / QML0。三张1366×768、150%DPI截图已实际查看，照片缩图等待就绪后捕获，未见来源/Info/底部动作重叠。

边界：支持当前资料库的多文件夹来源和C1当前来源；未将它描述为多个资料库同时挂载的持久多源导航。快速会话仍不要求入库，不增加评级。
