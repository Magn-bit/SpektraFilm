# AI 修图默认提示词

当前版本：1。实际默认值位于 [`desktop/ai_prompts.py`](../desktop/ai_prompts.py)，此文件记录流程和边界；不另维护一份容易漂移的完整提示词。

## 默认流程

1. **分析照片**：主动点击后发送当前照片的有界 sRGB 预览、必要参数和可用材料目录。根据主体、光线、曝光、色彩和细节给出 3–5 条具体观察。不会自动分析整批照片。
2. **推荐风格**：返回三种针对本片的待选方案；第一种自然整理，另外两种保持实用并有实际差异。每种包含适用理由、预期变化和可审核参数。选择前保持照片不变。
3. **选择并应用**：用户选择后，由现有影像引擎执行合法参数；一次应用对应一次撤销。原片、分辨率及导出质量不由模型改变。
4. **继续微调**：读取新的照片预览和当前参数，只修正用户提出的问题，返回一个待确认方案，避免重置或不断重推风格。

## 默认提示词的组成

| 常量 | 用途 |
| --- | --- |
| `SYSTEM_PROMPT` | 照片依据、审美原则、内容保护、材料与参数契约、作用范围和 JSON 输出纪律 |
| `ANALYZE_PROMPT` | 首次分析和三种风格推荐 |
| `REFINE_PROMPT` | 选择后的单方案微调 |
| `IMAGE_EDIT_PROMPT` | 生图接口的独立调色对照，不将生成图片冒充本地光谱显影 |

场景、用户意见、所选风格和控件数据作为结构化输入传入，不写死某张样片的景物，也不固化为青橙、日系或某一胶片。保持有意的暗调、剪影和现场氛围，不默认提亮所有照片。

## 参数及结果约束

- 仅使用应用允许的参数；最终绝对值、有限数值、合法范围、唯一字段和真实材料 ID。
- 胶片前曝光和印相曝光、相对白平衡和拍摄色温分别说明，不直接套用 LR/C1 数值。
- 只作用当前照片，保留裁切、几何和已有蒙版；无脚本、文件管理或自动导出能力。
- 选择前不应用，过期照片或旧参数对应的建议不可套回当前状态。
- 小预览不能证明 RAW 可恢复范围，也不能证明真实胶片或商业算法的精确还原。
- 生图模型与视觉分析模型分别配置；生图仅返回独立对照图，不能冒充参数建议。

## 本轮样片试验

用户指定 `gpt-image-2.5-sunburst`、生图专用中转站和最高质量。单次只请求一张；输入是 `DSC09118.ARW` 解码后的 1280×853 JPEG 预览。原始 RAW 不上传，密钥不写入源码、提示词或产品文档。该试验仅验证生图改图接口，不证明视觉分析、参数推荐或本地光谱出图效果。
