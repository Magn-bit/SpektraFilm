# Android 编辑器集成记录

2026-11-08；当前为工作区构建，发布版本由根任务统一更新。

## 已接通

- 沿用 Android 原生 View：照片和参数独立布局；竖屏上下、横屏左右；照片轻点显隐工具，保留当前分组；双指缩放、对比、蒙版、裁切各自处理手势。
- 裁切在原照片预览内操作，支持拖动位置/边角、原图/自由/1:1/3:2/4:3/16:9/XPan、交换比例方向、恢复/取消/应用；取消只丢弃草稿。没有新增全屏裁切 Dialog。
- 几何分组新增左右旋转 90° 图标；`quarter_turns` 与共享契约一致，先精确换向完整像素网格，再作拉直/透视/翻转。奇数转数交换输出宽高，裁切在旋转后的框中；旋转同时转动已有裁切区域，蒙版仍保存原片归一化坐标。
- 自然载入新照片，胶片显影可选。基础白平衡、曝光、明暗/色阶、饱和度/自然饱和度、纹理/清晰度/去朦胧、HSL、原色校准、RGB/亮度点曲线、三明暗区域色轮、画笔/线性/径向蒙版、旋转/翻转/透视、参数风格均接至共用原生编辑阶段。
- 基础“细节”提供独立锐化、亮度降噪、彩色降噪（0–100，默认 0）；在白平衡后、胶片前运行，关闭胶片时也只处理一次，不对模拟颗粒再降噪。最终分块的上下文采用修复、胶片光学和后期细节支持半径之和。
- 色温、色调和校准色相使用色带。曲线显示当前照片的亮度或通道直方图。曝光和双极参数有零位参考。滑块从首次接触直接拖动，长按圆点降低灵敏度，双击圆点恢复当前项；数值可以精确输入。
- 按单张照片保存有界撤销/重做历史；一次滑块拖动或蒙版手势为一条历史；全部恢复可撤销。界面用次级编辑操作菜单承载，避免三项重复占据主工具栏。
- 暗房次级入口包含相纸、印相曝光、Y/M、眩光、测光方式、自动曝光/滤色配光及场景宽容度。分析使用完整画面代理，迟到结果按照片和参数版本隔离；用户确认后才应用，只有有效宽容度拟合可以提交。
- 设置可选预览精度、RAW 缓存上限并清理空闲缓存；活动读取 lease 始终保留。批量导入只登记 URI 与小型参数，选中的照片才解码。
- 编辑操作菜单提供分类复制/粘贴和同步到所选照片：胶片、相纸、曝光、白平衡、基础、色彩、蒙版、裁切/几何；默认不复制蒙版和构图。批量选择胶片及同步均记录每张照片自己的历史，可逐张撤销。批量侧车写入合并为单个后台任务。

## 数据和最终输出

- `filmOnly()` 因兼容既有调用点保留名称，现为完整状态的边界校验，不再删除白平衡、色彩、曲线、蒙版或几何。
- Android 侧车版本从 2 升为 3。版本 1/2 仅迁移原本公开的胶片参数和显式 `crop`，强制旧照片胶片开启；不复活过去已撤下的隐藏编辑。版本 3 保存全部状态；新照片默认胶片关闭。
- JNI 直接调用共享 `editor_process`。胶片开启时为 capture pre → 光谱显影/印相 → editor post；关闭时为 editor all。输入/中间计算 float32，最终才转 RGB16。没有更换为显示缩略图或 Bitmap8 的 RAW 导出路径。
- 裁切单独使用原尺寸流式分块，不引入几何临时平面。旋转/透视/翻转先将原尺寸显影结果流式写入临时 RGB16 平面，再用 native mmap 进行一次最终采样；纯 90° 映射为整数像素一一对应。90° 交换宽高，主动裁切或配方缩小才减少输出像素。临时空间不足会明确失败，取消/异常/完成后清理平面。
- 预览和导出共用 pixel-centre homography。蒙版手势坐标反变换回 EXIF 方向已处理的原图归一化坐标。
- 互动预览与松手细节使用不同原生实例和有界任务队列。仅保留最新请求；导出前回收两条预览链的 GPU 暂存池。
- 导出配方与 `shared/output_recipes.py` 采用相同字段：JPEG8、PNG8/16、TIFF8/16、处理后线性 DNG16、相机 RAW 原片复制；可保存位深/色彩空间/JPG 质量/长边/命名/单层子文件夹/冲突策略/完成后打开。默认长边 0，即原尺寸；只有主动填写长边才使用线性光面积采样缩小，绝不从预览导出。
- PNG 是行级 RGB16 编码并嵌入 ICC；TIFF16 无损 Deflate；JPEG 在最终编码处量化一次并嵌入 ICC。Display P3 与 ProPhoto RGB 使用从共享色彩管理生成的真实矩阵和 ICC，通过 native 行转换改变像素和传递曲线，不能恢复更早 sRGB 工作阶段已裁掉的相机色域。
- 线性 DNG 使用 `PhotometricInterpretation=LinearRaw`、RGB16、D65 ColorMatrix/AsShotNeutral/完整像素区域，不是相机马赛克 RAW。已处理 DNG 与“RAW 原片不含调整”始终分开标识。
- 文件名默认 `{name}_{film}`，胶片关闭时后缀为 `_调整`；支持显式 `{index}`。同名编号或跳过均保留源文件；SAF 导出位置优先指向当前导入文档的父文件夹（提供方支持时），否则使用上次导出位置。显影/编码只占到 95%，写入目标文件完成后才到 100%。

- `assembleDebug`、`lintDebug`、`compileDebugAndroidTestKotlin` 通过。Lint 未使用 baseline 掩盖错误；仍有现有 API 弃用等警告。
- `android/tools/run_host_checks.py` 一次聚合检查通过：全部参数/侧车往返、旧版本迁移、原生 schema、撤销/重做、场景拟合参数保存、A7CR 大小的矩阵可逆与自动裁切、长按精调的锚点/RTL/端点/取消。
- 包含新原生 `editor_process`/`editor_analyze` 编译实现和 editor/restore SPIR-V 资源。
- 本阶段再次完成 `assembleDebug` / `lintDebug` / Android 测试源码编译；主机聚合检查包含分类同步的默认构图保护、命名/配方校验，以及实际 PNG8/16、TIFF16、线性 DNG16 的独立解码像素验证。LibRaw 能识别并准确解包导出的 DNG RGB16 样本。未采用哈希清单或目录哈希验收。

- 当前 ADB 无设备：没有声称在一加 15 实测新界面、原尺寸导出耗时、温控或截图。真机尺寸/大字体/手势导航/交互和完整 RAW 导出的最终验收仍待连接设备。

## 未冒充已完成的能力

这次 Android 尚未提供片边、物理日期后背、双图半格成品、Cineon 成品、宽色域软打样及自动镜头档案。参数风格只展示有真实参数实现的条目；当前没有 CLUT 资产，不放无效 LUT 入口。RAW 仍使用本地 LibRaw，自有编辑算法不声称为 Lightroom 或 Capture One 私有算法的逐像素复原。
