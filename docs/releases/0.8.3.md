# SpektraFilm · Windows 0.8.3 / Android 0.5.0

独立离线的 RAW 编辑与光谱胶片模拟。本次公开发布包含 Windows 便携版、现有 Android APK，以及各自对应的可重建源码。

## Windows 0.8.3

- 修正 ExifTool 发现顺序：优先随包工具和明确配置，避免元数据读取提前遍历系统 PATH。
- 统一应用身份与窗口图标，显式提供 Windows 大、小图标；保留暖白灰绿界面和中英衬线字体搭配。
- 包含 0.8.2 的 30 款胶片、9 种相纸、RAW／颜色工具、独立蒙版、原位裁切、批量处理、片边排版与输出配方。
- 主页使用项目所有者提供的真实 RAW，展示实际界面与处理结果。

完整解压 `SpektraFilm-0.8.3-Windows-x64.zip`，运行其中的 `SpektraFilm/SpektraFilm.exe`。不要单独移动 EXE 或删除 `_internal`。便携版无需安装 Python 或 WSL；原生 GPU 路径需要可用的 Vulkan 驱动。

## Android 0.5.0 · arm64-v8a

本次提供现有 **0.5.0 / code 23** APK 与它的匹配源码，未重新编译 Android。Windows 新功能不代表已经同步到手机版；本轮未重新进行 Android 真机验收。

## 验证与来源

本次在确切 Windows 包上检查启动、所提供 RAW 的预览和原生窗口图标，并对工具发现进行针对性回归；影像引擎与输出流程沿用未受影响的 0.8.2 检查，未重复全套 RAW 压力或全尺寸导出测速。当前 Qt 编辑画布为 SDR；相机兼容性、HDR 组合与平台差异见主页及构建说明。
