# SpektraFilm · Windows 0.8.4 / Android 0.5.0

独立离线的 RAW 编辑与光谱胶片模拟。本次改进 Windows 首次预览等待，并修复窗口／任务栏图标。产品主页使用项目所有者提供的真实 RAW 样片。

## Windows 0.8.4

- 快速与精细预览共享同一张原片的在途解码和光学准备，避免重复处理。
- 镜头资料准备与 RAW 解码重叠；解析索引按文件状态缓存，变更时重新读取。
- 七个次级窗口和未访问的工具分组按需创建，首次打开后保留状态。
- 有界预览合并 GPU 显示转换；最终输出继续读取完整原片，不改变分辨率或精度策略。
- 统一应用标识和原生大小图标，元数据工具优先使用随包或明确配置的路径。
- 工作区通过画布、抬升工具面板与底部操作区拉开层次；保留原有字体，浅色为暖白浅灰，深色采用中性炭灰。
- 照片栏上沿中央提供小三角收起／展开按钮，收起后仍可点击恢复；左上角月亮／太阳按钮直接切换并记忆外观。
- 排版面板统一工具与输出区的层次，放大片边样式缩略图，修复分类与实际样式不同步；扩展胶片的片边型号随当前材料更新，预览与导出使用同一路径。
- 片边增加按物理尺度生成的细密纹理与密度变化，透光颜色取自当前胶片的片基；孔缘保留柔和透光，照片内部不叠加片边纹理。
- 工具区与照片栏统一使用宽扁三角收起／恢复入口，移除照片栏重复的“添加”，导入统一留在顶部。

完整解压 `SpektraFilm-0.8.4-Windows-x64.zip`，运行 `SpektraFilm/SpektraFilm.exe`，保留整个 `_internal` 目录。便携版无需安装 Python 或 WSL；原生 GPU 路径需要可用的 Vulkan 驱动。

## 验证与来源

针对在途任务共享、原片与代理隔离、镜头缓存失效，以及延迟面板的首开／重开进行检查。启动首帧、首次预览、精细就绪与截图保存分开计时，具体结果见源码中的 `docs/windows-0.8.4-verification.md`；未重复全套大 RAW 或全尺寸导出测速。

Windows 未做正式代码签名，Android 使用开发调试签名。Qt 编辑画布为 SDR，格式、相机和 HDR 组合存在文档列出的边界。
