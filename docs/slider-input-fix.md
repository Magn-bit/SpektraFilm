# Windows 0.5.0 控件增量修复

2026-11-08。局部修复渐变轨道黑线、裁切比例菜单和连续拖动；沿用字体、布局与完整光谱，不改变最终输出尺寸或精度。

## 机制

- 原先 `ctrl.settings` 是每次读取均 `asdict` 的整个 QVariantMap。一次 `stateChanged` 会重算数百个可见／不可见绑定，并重建风格目录、输出配方等菜单模型。现在 QML 使用稳定的 `EditorBindings`，按字段通知；几何、蒙版、曲线、材料、预设、设置、配方各有独立通知。Python 的完整 settings 快照和持久化契约保留。
- 滑块位置和数值直接跟随指针；16ms 窗口内向控制器只提交最新值，松手同步提交末值。一次拖动一步撤销，Shift 细调、输入、双击复位和复位撤销仍生效。
- PIL→QImage 的两张预览转换移入工作线程，主线程交换不可变图像句柄；图片提供者利用 QImage 的共享存储，避免再次深拷贝。
- pre 请求只投影原生实际消费的白平衡、六原色和三项细节字段，不遍历蒙版。12000 点蒙版请求序列化中位耗时 13.47ms→0.0058ms，306220→420 字节；实际 Vulkan 对照确认像素不变。
- 锐化、明度降噪、彩色降噪加入源标识和胶片缓存失效条件；胶片强度混合基础图不再重复这三项处理。
- 渐变滑轨不再额外绘制下方黑线；普通轨道的已调节部分保留。裁切菜单原先有 7 项却自动宽度为 0，现固定 196 逻辑像素并锚定在按钮下方。

候选 EXE 实际导入、完整光谱、参数历史、原尺寸 TIFF/ICC 和正常退出通过，记录在 `output/release-slider-fix`。发布证据位于 `release/Evidence`。Android APK 沿用原 0.5.0/code23；本次没有 Android 界面或真机性能改动。
