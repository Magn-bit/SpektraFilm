# Windows 0.8.1 验证范围

本版沿用字体与暖白灰绿界面，光学移到基础，颜色校准优先呈现。连续标量输入使用本地拖柄位置、单字段通知及合并提交；设置改变后立即撤下旧原尺寸细节图，松手补全最终值。完整输出的尺寸和计算质量策略未变。

镜头状态以本机 LCP 实际应用结果为准，显示 EXIF 镜头及匹配配置名。未匹配、缺少元数据、焦距超限、未可靠应用与关闭状态分别反馈；配置路径放在悬停信息中，不捆绑本机 Adobe 配置文件。

自动白平衡使用分区中性区域、排除剪裁/高饱和区域、稳健统计及有界多起点拟合。置信度不足保留原值；采用本项目已有 Bradford 模型，不声称复刻 LR/C1 私有算法。

批量导出保存不可变任务快照和增量状态，恢复/重试保留每张设置，遇到现存目标自动改名；修复进度重复累计与结束回退。照片之间保留独立蒙版、活动层和撤销。
