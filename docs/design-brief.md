# SpektraFilm 设计约束

当前产品是独立离线的胶片光谱暗房，主路径为导入 → 选胶片 → 显影调整 → 原尺寸导出。基础修图、蒙版、曲线、色轮、HSL、几何、外部风格已从产品入口撤下。保留用户认可的大画布、单侧工具、底部照片序列与字体，不因局部精修更换 Qt Quick/Python 或 Android Kotlin/Canvas 技术栈。

## 视觉与层级

恢复此前的冷白、深灰与单一灰绿强调色：canvas #EBEEE9、surface #FCFCFB、white #FFFFFF、ink #252725、secondary #555E54、muted #626A60、rule #D8DDD2、border #BFC4BA、accent #667C65、accentInk #66745E、selection #EAF0E6、hover #E7E9E3。集中在两端 Theme / UiTheme，语义窗口圆点保留黄绿红。阴影仅服务照片与必要浮层，e0–e4 共用光源；不添加装饰图片、渐变或玻璃背景。

中文朱雀仿宋、英文与数字 Noto Serif SC。组合字体经过字形来源检查，许可随包保留；沿用 32/18/14/13 四级字阶，按实际字体视觉尺寸排版，不制造合成粗体。

常用曝光、颗粒、光晕、暗角、强度直接显示。以模块间距、细分隔线、稳定数值对齐区分层级；颗粒类型为一行菜单，四个选项在需要时出现，选择后不重建参数滚动区。折叠与否依据当前任务密度和操作频率，不机械照搬上游五标签或折叠组。

胶片档案展示名称、品牌、负片/反转片；主界面不标“推导/估计”。数据来源、拟合方法、校准条件及质量边界留在 docs/film-profile-expansion.md 与 provenance 元数据；不使用“厂家实测”等无证据表述。品牌由清单生成，未知品牌不假冒 Kodak。

## 交互与平台

Windows 右上黄/绿/红圆点对应最小化、最大化/还原、关闭；标题栏拖动、双击与系统缩放真实可用。恢复态16逻辑像素圆角，最大化0；先恢复窗口几何和状态再显示，断屏/DPI变化保证窗口可见。导出入口固定；文件拖放、多选、复制粘贴和快捷键不以界面常驻说明占位。

Android 按手机重排，画布优先，固定主要操作、紧凑参数区与照片浏览器；触控至少44dp，菜单48dp。SAF导入/目录授权保留平台流程，不能保证第三方提供方总能定位原片父目录。无实机不能把源码检查称为安全区/触控/帧率验收。

动效统一140/240/360/480ms、OutCubic；仅对必要状态使用 transform/opacity，遵从减少动态效果。拖柄实时跟随，不叠缓动；计算异步且仅保留最新任务，最终精算不能被迟到预览覆盖。菜单、导出、错误与应用内文件弹窗共用字体、表面、焦点与圆角。

## 输出与验证

最终始终从源图进行完整光谱计算，预览代理不能写入导出；JPG/TIFF保持源像素尺寸，RAW另存原字节。多选逐张保留设置，文件名为「原名_胶片名称」，同名编号、不覆盖原片。输出位置可选，目标下创建相应类型文件夹。

本轮观察源码与成品截图、菜单/键盘/滚动保持及实际导出；真实结果见 docs/validation.md。性能、设备运行与像素保真分开报告，不用“完美”“60fps”代替测量。macOS/iOS按用户决定暂停。
