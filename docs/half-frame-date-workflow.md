# Windows 半格工程与日期后背

## 参考与处理边界

以下载的 SpektraLab `2201f5fa4d256b0c742b46b8e31f8176a12ca6ea` 中 `Model/HalfFramePair.swift`、`Model/FilmEdge.swift`、`FilmEdge/FilmEdgeResolver.swift`、`Mac/Library/MacPairRows.swift` 为结构参考，实际像素由已集成的 native `pipeline/engine.cpp`、`pipeline/canvas_process.cpp` 与 `host/pair_source.cpp` 处理。没有采用画出的边框替代物理片条，没有修改本节点的 DLL 或 shader。

## 实际能力

- 半格拼接固定两个片位；每孔可替换、移除、平移、缩放和旋转，移除保持空片位而不重排另一张。
- 带片条时片门间距固定为原生相机推进的 1 mm；无片条时可调 0.5–2 mm，真实改变源线性画布和两个 native gate，而非仅调整界面。
- 横向、纵向与整组旋转共用准确的 gate 几何。关闭片条会隐藏不再生效的边缘/片门控件。
- 两孔的曝光、白平衡、几何和印相设置保留。扫描负片与正片跳过独立孔印相；关闭相纸效果会跳过预闪等相纸效果，亮度与滤色的基础印相语义保留。
- `.spektrapair` 使用 schema 1、原子写入、两个可为空的引用和便携几何/曝光/WB/印相字段。SpektraFilm 全部设置放在 `spektrafilm.settings` 扩展；未知 JSON 字段保留。照片失联会保留引用并显示可替换空位，明确移除才写 `null`。不把原照片复制进工程。
- 日期后背按片幅限制：135/半格支持液晶、点阵和 Data；645 支持 Data；XPan 等没有对应后背时禁用。无片条不能打印片边 Data，日期仍可位于画面内。
- 日期默认来自实际 EXIF，可选择年月日/月日年或手动覆盖。Data 默认来自快门与光圈，不制造缺失的 EXIF；日期和 Data 可同时曝光。半格有 Data 时字号上限为 1 倍。
- 原尺寸导出重新打开原始来源、完成原生显影并保存 TIFF16/ICC 等所选输出；预览像素不进入最终路径。

## 兼容范围

本项目工程能够完整往返本项目设置；上游便携孔字段及无关扩展保留，但上游独立保存的 look/自动测光策略尚未逐项映射到本项目，不能宣称跨软件外观完全一致。本项目最大取景缩放为 5 倍，上游 Placement 的限制可能为 4 倍。每孔 `dated` 读写保留，当前日期控制仍为共用后背；native 没有独立的第二孔 Data 字段，不能宣称两孔 Data 独立编辑。

## 关键验收

`scripts/verify_half_frame_workflow.py` 通过；证据为 `output/half-frame-review/report.json` 与同目录三张 1366×768 逻辑窗口截图。该节点使用一张 1200×800 的真实照片和 240 px 小代理，不重复历史大 RAW 压力测试。

- 0.5 与 2 mm 无片条输出为 160×243、160×253，纵向互换尺寸，均有两个真实 gate；带片条两值像素完全相同，证实间距固定为 1 mm。
- 关闭效果、扫描和正片的独立印相门控通过实际 native 像素比较。
- 日期格式限制、真实 EXIF Data、半格字号上限和日期+Data 像素变化通过。
- 文件保存/重开、取景保持、未知字段、空位/替换通过。
- 原源无片条导出为 1257×800、16 位 TIFF，带 ICC；预览长边仅为 240，证明导出没有使用预览图。
- QML 错误为 0。取景和日期截图已检查：导出区有独立不透明区域，参数在上方滚动，操作不重叠。

本节点为源码和实际 native 处理验收；最终 Windows 发布物仍需主集成的成品节点。
